# Stufe 4c: GUI v3 nach den Detail-Mockups – Implementierungsplan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Die Oberfläche folgt den drei Detail-Entwürfen in `docs/recherche-cockpit/images/` (Rahmen mit Suche, Dashboard, Geldflüsse & Profiteure mit Empfänger-Spalte und Karte „Politische Verantwortung“, Empfänger-Detailseite „Wer profitiert?“, Ministerien-Detailkarte, Politik & Verantwortung, Haushaltssimulator), mit Platzhaltern für Bilder und ohne Elemente, für die es keine Daten gibt.

**Architecture:** Neue Ansichten `Dashboard.svelte`, `Simulator.svelte`, `PolitikVerantwortung.svelte`; `Fluss.svelte` bekommt optional eine Empfänger-Spalte über `sankeyData.ts`; `EmpfaengerSeite.svelte` wird nach dem Entwurf neu gegliedert; `Ministerien.svelte` bekommt die Detailkarte; gemeinsame Bausteine `Avatar.svelte` (Initialen, Logo-Kachel), `Kennzahl.svelte` (Symbolkachel + Zahl), `Suche.svelte`; reine Modelle `suche.ts`, `dashboard.ts`, `profiteure.ts`, `verantwortung.ts` mit Tests. Lucide-Symbole über `lucide-svelte`.

**Tech Stack:** Svelte 5, TypeScript, vitest, d3-sankey, lucide-svelte 1.0.1 (MIT).

**Spec:** `docs/superpowers/specs/2026-11-01-bundeshaushaltstracker-design.md` §4.11 (bindend), §4.10, §4.6a, §4.7a.

## Global Constraints

- Quellenregel: jede Zahl mit Jahr, Soll/Ist, Quelle; keine Addition über Quellen; keine Wertung; keine leeren Hüllen für Vergaben, Auffälligkeiten, Abstimmungen, Export.
- Teilen-Links bleiben gültig; neue Ansichten `dashboard`, `simulator`, `politik` als Ansichts-Ids; `a=fluss` bleibt Geldflüsse & Profiteure.
- Farben über Tokens aus `app.css`; Bilder nur als Platzhalter (Initialen, Kürzel); Parteikennung als Etikett.
- Suiten grün: `cd web && npm run check && npm test -- --run`; svelte-check ohne Warnungen.

## Review Focus

1. Die Empfänger-Spalte im Sankey zeigt nur Empfänger, die laut Haushaltstitel oder Lobbyregister Geld aus dem fokussierten Einzelplan erhalten; Beträge je Quelle, nicht addiert; Rest als „weitere“. Test Task 3.
2. „Politische Verantwortung“ nennt nur die Leitung des Jahres (wie Ministerien), nie eine Person für einen Einzelplan, den sie nicht leitet. Test Task 3.
3. Die Suche findet Einzelpläne, Empfänger und sichtbare Akten; nicht sichtbare Akten erscheinen nicht. Test Task 1.
4. „Zuständiges Ministerium“ auf der Empfänger-Seite ist der Einzelplan mit dem meisten Geld je Quelle (Haushalt vor Lobbyregister), mit Angabe der Quelle. Test Task 4.
5. Der Haushaltssimulator rechnet mit denselben Faktoren wie das Seitenpanel; Defizitquote = Neuverschuldung / Ausgaben. Test Task 6.
